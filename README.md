# Portfolio Ivan

Sito statico (HTML/CSS/JS) pensato per GitHub Pages. Nessun server, nessun costo.

- `index.html`, `css/`, `js/` → sito pubblico
- `data/photos.json` → elenco di foto, categorie, progetti e testi
- `foto/` e `thumbs/` → immagini ottimizzate
- `admin/` → pagina per aggiungere/modificare foto (serve il tuo token GitHub personale)
